Все говорят: на C1 нужен сложный язык. Konjunktiv, пассив, Nominalstil.

Нужен. Но есть ошибка дороже грамматики.

В официальных советах telc есть текст на тему «групповая работа». Грамотный, длинный. А за выполнение задания он получил C. Потому что весь был про работу в офисе. А задание было про семинар.

<p class="punch">Сначала попади в ситуацию. Потом блесни языком.</p>

## Что за задание

| Что | Как |
|---|---|
| Выбор | одна тема из двух |
| Ситуация | семинарская работа: рассмотреть тему с разных сторон |
| Опора | две противоположные цитаты, их можно использовать или нет |
| Что написать | свой аргументированный текст: введение, основная часть, вывод |
| Объём | минимум 350 слов |
| Время | 70 минут |
| Баллы | 48: четыре критерия по 12 |

Вот задание в том же формате, тема моя.

## Как считают <span class="hl">48 баллов</span>

Каждый критерий оценивают одной буквой. Буква превращается в баллы.

<Score items={[
  { name: 'A: в каждом отношении C1', pts: 12, max: 12, color: 'var(--lime)' },
  { name: 'B: в основном C1', pts: 8, max: 12, color: 'var(--teal)' },
  { name: 'C: в основном не C1', pts: 4, max: 12, color: 'var(--sun)' },
  { name: 'D: совсем не C1', pts: 0, max: 12, color: 'var(--pink)' },
]} />

| Критерий | Что это значит по-человечески |
|---|---|
| Aufgabengerechtheit | задание раскрыто полностью, есть «roter Faden», есть критический взгляд на тему, текст подходит к ситуации |
| Korrektheit | почти нет ошибок в формах, порядке слов и орфографии; редкие ошибки только в сложных конструкциях |
| Repertoire | широкий словарь, сложные предложения там, где они уместны; мало повторов |
| Kommunikative Gestaltung | абзацы, связки, местоимения, синонимы: текст держится вместе |

Четыре буквы B дают 32 балла. Это нормальный результат для C1. Для сравнения: вся письменная часть требует 99 из 166.

<Callout type="trap" title="Три способа потерять баллы до первой ошибки">
  <p><b>Мимо темы.</b> Отметка «Thema verfehlt» означает D во всех четырёх критериях. Ноль.</p>
  <p><b>Мимо ситуации.</b> Тема про семинар, а ты пишешь про фирму. Тема та же, ситуация нет. В советах telc такой текст получил C за выполнение задания.</p>
  <p><b>КАПСЛОК.</b> Текст только заглавными или только строчными буквами telc понижает на одну ступень по Korrektheit. Это прямо написано в официальных советах. Запятые там тоже упомянуты.</p>
</Callout>

## Схема на пять абзацев

| Абзац | Задача | Примерно слов |
|---|---|---|
| Введение | тема, почему спорят, две позиции, план текста | 50–60 |
| Аргументы «за» | 2–3 довода и пример | 70–80 |
| Аргументы «против» | 2–3 довода и пример | 70–80 |
| Своя позиция | не просто «я за», а условие, различие, третий путь | 60–70 |
| Вывод | итог, ответ на вопрос темы, взгляд вперёд | 50–60 |

Сумма 300–350, поэтому целься в верхнюю границу каждой строки. Абзац «своя позиция» это то, что отличает C1 от B2. Критерий 1 прямо требует критической работы с темой: не пересказ «за и против», а твой вывод из них.

## План на 70 минут

<Steps>
  <Step title="5 минут. Выбор темы">
    <p>Выбирай ту, где за минуту придумаешь по два довода с каждой стороны. Не ту, что «умнее».</p>
  </Step>
  <Step title="7 минут. План ключевыми словами">
    <p>Пять строк, по одной на абзац. Доводы, пример, твой «третий путь». Не черновик: telc прямо советует не писать текст дважды.</p>
  </Step>
  <Step title="45 минут. Чистовик">
    <p>Абзац за абзацем. После каждого абзаца прикинь число слов. К 40-й минуте письма должно быть около 300.</p>
  </Step>
  <Step title="10 минут. Проверка">
    <p>Глагол в придаточном в конце? Падеж после предлога? Запятые перед dass, weil, obwohl, die/der? Заглавные у существительных? Номер задания в бланке?</p>
  </Step>
  <Step title="3 минуты. Запас">
    <p>Если всё готово, добавь одно предложение-пример туда, где аргумент голый.</p>
  </Step>
</Steps>

## Ошибки, которые съедают баллы

| Ошибка | Что проседает | Как чинить |
|---|---|---|
| Пишешь про работу или жизнь вообще, а тема про семинар | Aufgabengerechtheit | Пример и вывод из учёбы |
| Только «за и против», без своей позиции | Aufgabengerechtheit | Абзац «своя позиция» с условием или различием |
| Меньше 350 слов | Aufgabengerechtheit | Считай слова после каждого абзаца |
| Три раза «außerdem» | Repertoire, Gestaltung | Hinzu kommt, Zudem, Darüber hinaus |
| Длинные фразы с ошибками в каждой | Korrektheit | Сложно там, где уверен; просто там, где нет |
| Нет абзацев | Kommunikative Gestaltung | Пять абзацев с пустой строкой |

## Шпаргалка

- Одна тема из двух, **минимум 350 слов**, 70 минут.
- Ситуация семинара: пример и вывод из учёбы.
- Пять абзацев: введение, за, против, своя позиция, вывод.
- 4 критерия × 12 = **48**. A 12, B 8, C 4, D 0.
- Мимо темы = 0. КАПСЛОК = минус ступень.
- План ключевыми словами, без черновика.
