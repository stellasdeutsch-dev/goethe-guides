Все говорят: в письме главное грамматика.

В telc можно написать без единой ошибки и получить ноль. Забыл номер задачи в бланке. Всё.

Можно получить мало и с хорошим немецким. Раскрыл пункты по одной фразе. Перечислил их без связок. Перепрыгнул с Sie на du.

Письмо в telc B2 это не сочинение. Это e-mail человеку, которому от тебя что-то нужно. Или тебе от него.

## Что за задание

| Что | Как на экзамене |
|---|---|
| Время | 30 минут, включая выбор задачи |
| Выбор | одна из двух задач, обычно A: просьба об информации, B: жалоба |
| Тип текста | полуформальный e-mail в ответ на объявление или рекламу |
| Объём | минимум 150 слов |
| Пункты | 4 Leitpunkte: раскрыть 3 или 2 + свой аспект |
| Обязательно | тема (Betreff), обращение, вступление, концовка |
| Баллы | 45, это 15 % всего экзамена |

Задание выглядит так. Тема наша, формат как в Übungstest.

Последний абзац задания это не вода. Тему, обращение, вступление и концовку тебе диктуют прямо. Их отсутствие бьёт по оценке.

## Как считают <span class="hl">45 баллов</span>

Три критерия. Каждый получает букву.

- **I. Aufgabenbewältigung.** Раскрыты ли пункты и подходит ли текст к ситуации. Уровень B2: своя позиция, ясно и с учётом адресата.
- **II. Kommunikative Gestaltung.** Связность, логика, связки, регистр, словарный запас.
- **III. Formale Richtigkeit.** Грамматика, орфография, пунктуация.

  { name: 'C', pts: 1, max: 5, note: 'Раскрыт один пункт', color: 'var(--sun)' },
  { name: 'D', pts: 0, max: 5, note: 'Ни одного', color: 'var(--pink)' },
]} />

Это шкала по критерию I. По II и III буквы те же, баллы те же. Потом сумма × 3. Три пятёрки дают 15 × 3 = 45.

Письмо читают двое. Если оценки расходятся, решает вторая.

### Правила, которые стоит знать наизусть

Всё это из критериев в Übungstest 1:

- **Один пункт это больше одной фразы.** «Angemessene Behandlung» требует больше одного сложного предложения.
- **Без темы, обращения и прощания** по критерию II не будет A.
- **B по критерию II не дадут,** если регистр неверный или скачет, если словарь ниже B2, если пункты идут списком без логической связи.
- **Упрощение карается.** Если содержание и язык упрощены, оценку снижают.
- **Thema verfehlt** (текст почти не связан с задачей) означает D по всем трём критериям.
- **Situierung verfehlt** (тема та, но ситуация другая) означает D только по критерию I. II и III ещё оценят.

Пример telc: нужно попросить информацию о практике в фирме. Написал жалобу на продукцию фирмы? Тема мимо. Написал заявление о приёме на работу? Ситуация мимо.

Посмотри на связки между абзацами: Umso überraschter, Außerdem, daher. Это то, что telc называет логической связью пунктов. Без них текст становится списком.

## Ошибки, которые съедают баллы

| Ошибка | Что проседает | Как чинить |
|---|---|---|
| Пункт одной фразой | Критерий I | 3–4 предложения на пункт: факт, причина, пример или вопрос |
| Пункты списком без связок | Критерий II, максимум C | Außerdem, daher, umso, zwar … aber, schließlich |
| Sie и du вперемешку | Критерий II | Везде Sie, Ihnen, Ihr с большой буквы |
| Нет темы письма | Критерий II, уже не A | Betreff первой строкой |
| Заявление вместо просьбы об информации | Критерий I = D | Ещё раз перечитай, что просят сделать |
| Заученный шаблон не по теме | Критерий I, а то и всё | Шаблон для рамки, содержание под задачу |
| Нет номера задачи в бланке | 0 за всё | Номер переносишь первым делом |

## Шпаргалка

- Номер задачи в бланк → первым делом.
- 2 минуты на выбор → не читай обе задачи подробно.
- Три пункта (или два + свой) → каждый 3–4 предложения.
- Тема, обращение, вступление, концовка, прощание → всё на месте.
- Sie везде → ни одного du.
- Связки между пунктами → иначе это список.
- 150 слов минимум → целься в 160–190.
