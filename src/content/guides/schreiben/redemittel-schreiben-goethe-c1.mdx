На экзамене из ста вспоминаются три. И все три про мнение.

А пункт просит объяснить причины. Или показать понимание. Или предложить компромисс.

## Функции из <span class="hl">описания экзамена</span>

Goethe строит каждый пункт задания вокруг Sprachfunktion. Речевого действия. Вот что названо в официальном описании и в Modellsatz.

| Часть | Функции, которые называет Goethe |
|---|---|
| Teil 1, форум | объяснить, привести аргументы, разобрать на примерах, высказать мнение, назвать причины |
| Teil 1, официальный образец | объяснить критерии, аргументировать на примере, назвать причины против, объяснить альтернативу |
| Teil 2, письмо | обратить внимание на проблему, предложить, описать, вежливо показать понимание |
| Teil 2, официальный образец | показать понимание обстоятельств, назвать, что затруднено, описать приемлемые условия, предложить компромисс |

Фразы ниже разложены ровно по этим функциям. Нашёл в задании глагол, открыл нужную группу.

<Callout type="tip" title="Две фразы на функцию">
  <p>Выбери из каждой группы две фразы. Напиши каждую от руки три раза в разных предложениях. Скажи вслух. На экзамене голова занята мыслью, фразы должны выходить сами.</p>
</Callout>

<Callout type="trap" title="Порядок слов после мнения">
  <p><span lang="de">Meines Erachtens <b>ist</b> das sinnvoll.</span> Meines Erachtens занимает первое место, глагол второй.</p>
  <p><span lang="de">Ich bin überzeugt, dass das sinnvoll <b>ist</b>.</span> После dass глагол в конец. Перепутать эти два порядка это самая частая ошибка в Strukturen.</p>
</Callout>

## Связки C1 и <span class="hl lime">порядок слов</span>

Связка без правильного порядка слов это минус в Strukturen, а не плюс в Kohärenz.

| Связка | Порядок | Пример |
|---|---|---|
| zwar … aber | глагол сразу после zwar | Zwar ist das teuer, aber es lohnt sich. |
| nicht nur … sondern auch | обычный | Das spart nicht nur Zeit, sondern auch Geld. |
| sofern | глагол в конец | Das funktioniert, sofern alle mitmachen. |
| indem | глагол в конец | Man spart Energie, indem man weniger heizt. |
| zumal | глагол в конец | Das ist sinnvoll, zumal es kaum etwas kostet. |
| wohingegen | глагол в конец | Junge Leute zahlen digital, wohingegen Ältere oft Bargeld nutzen. |
| infolgedessen | глагол сразу после | Infolgedessen sinken die Kosten. |
| nichtsdestotrotz | глагол сразу после | Nichtsdestotrotz halte ich das für richtig. |
| je … desto | je + конец, desto + глагол | Je früher man beginnt, desto leichter fällt es. |

<Callout type="life" title="Правило трёх начал">
  <p>Перечитай свой текст и посмотри только на первые слова предложений. Три подряд начинаются одинаково? Поменяй одно. Эксперты Goethe в комментарии к образцу отдельно отметили разные начала предложений как плюс в Kohärenz.</p>
</Callout>

## Nomen-Verb-Verbindungen

Устойчивые пары «существительное + глагол». В комментариях Goethe к образцам их правильное использование отмечено как плюс в Wortschatz. Одна-две на текст, и он звучит взрослее.

<Phrases title="Устойчивые сочетания">
  <Phrase de="Unternehmen sollten stärker Rücksicht auf Familien nehmen." ru="Компаниям стоит больше считаться с семьями. (Rücksicht nehmen auf + Akk)" />
  <Phrase de="Viele nehmen längere Wege in Kauf, um Geld zu sparen." ru="Многие мирятся с долгой дорогой, чтобы сэкономить. (in Kauf nehmen)" />

  <Phrase de="Die Stadt sollte mehr Räume für Jugendliche zur Verfügung stellen." ru="Городу стоит предоставить больше помещений для молодёжи." />
  <Phrase de="Man sollte auch andere Lösungen in Betracht ziehen." ru="Стоит рассмотреть и другие решения." />
  <Phrase de="An dieser Regelung wird zunehmend Kritik geübt." ru="Это правило всё сильнее критикуют. (Kritik üben an + Dat)" />
</Phrases>

## Шпаргалка

- **Причины** → Das lässt sich darauf zurückführen, dass … / Ausschlaggebend ist, dass …
- **Аргумент** → Dafür spricht vor allem, dass … / Hinzu kommt, dass …
- **Пример** → Man denke nur an … → Gerade dieses Beispiel zeigt, dass …
- **Оговорка** → Zwar …, aber … / Das gilt nur, sofern …
- **Вывод** → Alles in allem … / Unterm Strich …
- **Понимание** → Mir ist bewusst, dass … aus guten Gründen …
- **Просьба** → Wäre es möglich …? / Ich wäre Ihnen dankbar, wenn …
- **Компромисс** → Als Kompromiss würde ich vorschlagen, dass …

<p class="punch">Фраза это ключ. Но дверь каждый раз новая.</p>
