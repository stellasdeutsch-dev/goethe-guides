## B1 Lesen Teil 3
| Факт | Источник | Цитата |
|---|---|---|
| Цель «Zur Orientierung lesen», тип «Zuordnung», 7 заданий | MS B1 p.6 | «3 Zur Orientierung lesen Zuordnung 7» |
| 10 минут | MS B1 p.12 | «Teil 3 Arbeitszeit: 10 Minuten» |
| Ситуации 13–19, объявления A–J (10 штук) из разных немецкоязычных СМИ | MS B1 p.12 | «Lesen Sie die Situationen 13 bis 19 und die Anzeigen A bis J aus verschiedenen deutschsprachigen Medien.» |
| Каждое объявление один раз | MS B1 p.12 | «Sie können jede Anzeige nur einmal verwenden.» |
| Объявление из примера больше нельзя | MS B1 p.12 | «Die Anzeige aus dem Beispiel können Sie nicht mehr verwenden.» |
| Ровно одной ситуации ничего не подходит → 0 | MS B1 p.12 | «Für eine Situation gibt es keine passende Anzeige. In diesem Fall schreiben Sie 0.» |
| Та же инструкция в Übungssatz | ÜS B1 Teil 3 | дословно то же |
| Перед ситуациями одна вводная фраза о том, кто и что ищет | MS B1 (курс немецкого закончился, коллеги хотят учиться дальше), ÜS B1 («In den Sommerferien möchten junge Menschen Geld verdienen und suchen dafür passende Ferienjobs.») | |
| На бланке у Teil 3 колонки a–j и 0 | Antwortbogen MS p.30 (скан) | |
| В решениях MS p.31 ровно одна строка с 0 (задание 14) | Lösungen MS p.31 (скан) | |

Арифметика (моя, из официальных цифр): 10 объявлений − 1 из примера = 9 на 7 ситуаций; одна ситуация = 0 → используются 6, лишних 3. В MS решения: 13 d, 14 0, 15 f, 16 b, 17 a, 18 c, 19 h, пример i → не использованы e, g, j.

Наблюдение по MS: среди лишних объявлений есть вакансии («… sucht engagierte Trainer», «Verlag … sucht Lektor») с теми же ключевыми словами, что в ситуациях. В статье описано обобщённо, без копирования.

## A2 для сравнения
- A2 Lesen Teil 4 «Anzeigen verstehen, Zuordnen, 5» [MS A2 p.3].
- Инструкция: «Lesen Sie die Aufgaben 16 bis 20 und die Anzeigen a bis f. Welche Anzeige passt zu welcher Person? Für eine Aufgabe gibt es keine Lösung. Markieren Sie so X. Die Anzeige aus dem Beispiel können Sie nicht mehr wählen.» [MS A2 Lesen Teil 4]
- Бланк A2, Teil 4: колонки a b c d e f x. [MS A2 Antwortbogen]
- Итог: в A2 «нет пары» = X, в B1 = 0.

## Тренировочный набор в статье
Мой. Тема «хобби на осень» (не пересекается с MS: Deutsch lernen, ÜS: Ferienjobs, A2: Lokale).
Ключ: 0 → d; 13 → f; 14 → i; 15 → j; 16 → g; 17 → 0; 18 → a; 19 → c. Лишние: b, e, h.
