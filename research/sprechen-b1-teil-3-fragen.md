## Формат
| Факт | Цитата | Источник |
|---|---|---|
| Teil 3 ~2 мин (бланк кандидата) | «In Teil 3 sprechen Sie über Ihr Thema und das Ihres Partners/Ihrer Partnerin (circa 2 Minuten).» | MS S.24, ÜS S.24 |
| По правилам 1–2 мин на человека | «Teil 3 circa 1–2 Minuten pro PTN» | DB §3 |
| Цель (Überblick) | «Situationsadäquat reagieren — Teilnehmende geben einander Feedback zur Präsentation bzw. reagieren darauf und stellen einander je eine Frage bzw. reagieren darauf» | MS S.6 |
| После своей презентации | «Reagieren Sie auf die Rückmeldung und auf Fragen der Prüfer/-innen und des Gesprächspartners/der Gesprächspartnerin.» | MS S.28 |
| После презентации партнёра: a) отзыв | «a) Geben Sie eine Rückmeldung zur Präsentation Ihres Partners/Ihrer Partnerin (z. B. wie Ihnen die Präsentation gefallen hat, was für Sie neu oder besonders interessant war usw.).» | MS S.28, ÜS S.28 |
| b) вопрос | «b) Stellen Sie auch eine Frage zur Präsentation Ihres Partners/Ihrer Partnerin.» | MS S.28 |
| Второй экзаменатор тоже даёт отзыв и задаёт вопрос | «Bei Aufgabe 3 gibt der/die andere Prüfende Rückmeldung und stellt eine Frage.» | DB §3.3 |
| Кто спрашивает | «In Teil 3 geben der/die andere Teilnehmende und der/die zweite Prüfende, die bei der Präsentation zugehört haben, Rückmeldung zu dem Gehörten und stellen Fragen. Der/Die Teilnehmende, der/die den Vortrag gehalten hat, beantwortet diese Fragen.» | DB §3.3 |
| Один: вопросы только от экзаменатора | «Im Fall einer Einzelprüfung stellt nur der/die Prüfende Fragen zum Vortrag.» | DB §3.3 |
| Слова экзаменатора | «Hören Sie gut zu und überlegen Sie sich eine Frage, die Sie stellen wollen, wenn Herr … /Frau … fertig ist.» / «Geben Sie Herrn/Frau … eine Rückmeldung darüber, wie Ihnen die Präsentation gefallen hat. Und bitte stellen Sie auch eine Frage.» / «Mein/-e Kollege/Kollegin hat auch noch eine Frage an Sie.» | MS S.44 |

Порядок по Hinweise (MS S.44): TN1 презентует → TN2 отзыв + вопрос → TN1 отвечает → Prüfer 2 вопрос → TN1 отвечает → затем то же для TN2.

## Баллы Teil 3 (Bewertungsbogen ÜS S.48, MS S.47; проверено визуально)
- Только один критерий: Erfüllung 16 / 12 / 8 / 4 / 0.
- Описание: «Sprachfunktionen (Rückmeldung, Frage stellen, beantworten) Inhalt Umfang». A «Sprachfunktionen in Inhalt und Umfang angemessen behandelt», B überwiegend, C teilweise, D kaum, E «nicht bewertbar». [MS S.45]
- Aussprache оценивается по всем трём частям вместе: 16 / 12 / 8 / 4 / 0.

## НЕ подтверждено
- Можно ли записывать вопрос во время презентации партнёра: в DB сказано только про заметки из подготовки («in der Vorbereitungszeit erstellten … Notizen»). Не утверждаем, советуем запомнить ключевое слово.
- Штраф за переспрос: в критериях нет. Пишем как совет: переспросить лучше, чем ответить мимо.
- Тема модельного партнёра (Homeoffice) своя; личные детали персонажей вымышлены как пример, не как опыт автора.
- «Отзыв с вопросом 20–30 секунд», «ответ 2–3 предложения»: советы автора, выведены из лимита 1–2 мин на человека (DB §3). Официальных норм нет.
- «16 баллов ≈ шестая часть модуля»: 16 из 100, расчёт автора.
