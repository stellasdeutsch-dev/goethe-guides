### Пересчёт Lesen (ключ, печ. стр. 20–21)
- Aufgabe 1 (5 Items): 1 верный = 1 балл, макс. 5.
- Aufgabe 2 (5 Items): 1 = 1, макс. 5. Одну букву можно использовать несколько раз, каждое решение оценивается отдельно.
- Aufgabe 3 (20 Items): 20–18 → 5, 17–15 → 4, 14–11 → 3, 10–7 → 2, 6–4 → 1, 3–0 → 0.
- Aufgabe 4 (10 Items): 10–9 → 5, 8–7 → 4, 6–5 → 3, 4–3 → 2, 2–1 → 1, 0 → 0.
- A3/A4: засчитываются и другие варианты, если «sinngemäß passen und grammatikalisch korrekt»; часть орфографических ошибок прощают (двойные согласные, k-ck, s-ß, большая/маленькая буква, ai-ei, ä-e, v-f, d-t; не прощают a-ä, o-ö, u-ü; лишняя/пропущенная буква = ошибка). В A3 ответ может быть длиннее 3 букв, если подходит.

### Пересчёт Hören (ключ, печ. стр. 21–22)
- Aufgabe 1 (10 Items, R/F): 1 = 1, макс. 10. Пусто или оба креста = 0 за Item. Все R или все F во всей Aufgabe = 0 за всю Aufgabe.
- Aufgabe 2 (30 Items): Messpunkte, макс. 45. Дихотомические (одно значение) 1 MP; политомические (несколько галочек) 2 MP если всё верно, 1 MP если верно не меньше 50 % клеток, 0 если меньше. Каждая клетка, не совпавшая с ключом, неверна (и лишний крест, и пустая клетка). Вся строка (1, 5, 6, 7, 8) отмечена целиком или пустая = 0 за Items строки. Орфография чисел/слов не важна, если однозначно.
- Пересчёт MP → баллы: 45–43 → 10, 42–40 → 9, 39–37 → 8, 36–33 → 7, 32–29 → 6, 28–24 → 5, 23–19 → 4, 18–14 → 3, 13–9 → 2, 8–4 → 1, 3–0 → 0.
- Aufgabe 1 звучит zwei Mal, Aufgabe 2 ein Mal, перед каждой 90 секунд на чтение (лист заданий).
- MP3 в ZIP: ZB2_MS_A1_270917.mp3 = 1044,6 с (около 17,5 мин), ZB2_MS_A2_270917.mp3 = 460,9 с (около 7,7 мин). Длительность проверена ffprobe, аудио не воспроизводилось. Транскриптов в бесплатном Modellsatz нет.

### Schreiben (Auswertungsbogen Vers. 7.0)
- Schreiben 1 (formelles E-Mail, Beschwerde, ca. 120 Wörter): A (Aufgabe) 0 / −1 / −2 / −3 / n. b.; K 3; T 2; L 5; F 5 = 15. «n. b. oder 0 Punkte = gesamte Aufgabe 1 nicht bestanden».
- Schreiben 2 (Meinungsäußerung, выбор A/B, ca. 120 Wörter): TL: меньше 50 % слов = n. b.; A 0…−3 / n. b. (явная позиция к инпуту, обоснование, опыт, ситуация в стране); K 2; T 3; L 5; F 5 = 15.
- «eigenständig im Sinne von „selbstständig“ und nicht zitierend übernommen»: формулировки из задания не переписывать.
- Schreiben итого max 30 / min 15.

### Sprechen (Auswertungsbogen Vers. 4.0)
- Aufgabe 1, 2, 3: по 3 балла (3 / 2 / 1–0) за выполнение задачи и коммуникативную цель.
- По всему разговору: Ausdruck/Redemittel 7, Verständlichkeit/Aussprache/Flüssigkeit 7, Formale Richtigkeit 7.
- Итого 30, мин. 18. «0 Punkte bei diesem Kriterium = gesamte mündliche Prüfung nicht bestanden» (для трёх общих критериев).

## Решения по бланкам на сайте
- AnswerSheet считает «верные × factor» одним коэффициентом. Поэтому:
  - `oesd-b2-ms-lesen`: Aufgabe 1 + 2, factor 1, max 10 (точно по ÖSD).
  - `oesd-b2-ms-lesen-3`: Aufgabe 3, 20 Items, factor 1, max 20 = число верных; пересчёт в баллы по таблице в тексте (нелинейный).
  - `oesd-b2-ms-lesen-4`: Aufgabe 4, factor 0,5, max 5. Math.round(n × 0,5) совпадает с официальной таблицей для всех n = 0…10.
  - `oesd-b2-ms-hoeren`: Aufgabe 1, factor 1, max 10 (точно).
  - `oesd-b2-ms-hoeren-2`: Aufgabe 2, 30 клеток, считает точные совпадения; Messpunkte и пересчёт по таблице в тексте.
- В A3, A4 и Hören A2 на экзамене ответ пишут сами. На сайте варианты выбора: правильный из ключа + наши дистракторы (грамматически или по смыслу неверные). Для Hören A2 в вариантах стоят значения из той же строки таблицы.
